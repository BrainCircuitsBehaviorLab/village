## Task Examples (Arduino)

The same six training tasks run by an Arduino instead of a Bpod (`BEHAVIOR_CONTROLLER` set to `OTHER`). Each page has the task and the Arduino firmware it needs.

| File | What it shows |
| :--- | :--- |
| [arduino_1_habituation.py](arduino_1_habituation.md) | Arduino version of [bpod_1_habituation.py](bpod_1_habituation.md): the same task and states (see its diagram), run by an Arduino that reports every state and poke to the Raspberry Pi. |
| [arduino_2_passive.py](arduino_2_passive.md) | Arduino version of [bpod_2_passive.py](bpod_2_passive.md): the same task and states (see its diagram), run by an Arduino that reports every state and poke to the Raspberry Pi. The ITI and the penalty, if any, are timed by the Raspberry Pi. |
| [arduino_3_active.py](arduino_3_active.md) | Arduino version of [bpod_3_active.py](bpod_3_active.md): the same task and states (see its diagram), run by an Arduino that reports every state and poke to the Raspberry Pi. The ITI and the penalty, if any, are timed by the Raspberry Pi. |
| [arduino_4_center_initiated.py](arduino_4_center_initiated.md) | Arduino version of [bpod_4_center_initiated.py](bpod_4_center_initiated.md): the same task and states (see its diagram), run by an Arduino that reports every state and poke to the Raspberry Pi. The ITI and the penalty, if any, are timed by the Raspberry Pi. |
| [arduino_5_introduce_penalty.py](arduino_5_introduce_penalty.md) | Arduino version of [bpod_5_introduce_penalty.py](bpod_5_introduce_penalty.md): the same task and states (see its diagram), run by an Arduino that reports every state and poke to the Raspberry Pi. The ITI and the penalty, if any, are timed by the Raspberry Pi. |
