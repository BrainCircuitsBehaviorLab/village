## Plots

Live, per-session and per-subject plots: how to write them is explained in [Custom Plotting](../protocols/plots.md). The example files below are the plots of the example project.

| File | What it shows |
| :--- | :--- |
| [online_plot.py](online_plot.md) | Live plot of the running session: cumulative trials and rolling accuracy. |
| [session_plot.py](session_plot.md) | Plot of a finished session, built from whichever columns the task registered. |
| [subject_plot.py](subject_plot.md) | Plot of a subject's history across sessions: sessions, water, weight and trials, also per task. |
