## Functions

Direct functions, sounds and screen stimuli: how they work is explained in [Direct, Audio & Video Functions](../protocols/functions.md). The example files below are the ones used by the example tasks.

| File | What it shows |
| :--- | :--- |
| [direct_functions.py](direct_functions.md) | The direct functions used by the example tasks (sounds, camera messages, screen stimuli...), also available as buttons in the FUNCTIONS tab. |
| [sound_functions.py](sound_functions.md) | Sound generators (tones, white noise) used by the direct functions, and the list of sounds offered in the sound calibration. |
| [video_functions.py](video_functions.md) | Screen stimulus generators (shapes, a moving circle, images, a video) used by the direct functions. |
